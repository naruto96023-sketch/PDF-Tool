📦 Complete 100% Offline Air-Gapped Setup

To run Suresh PDF on computers with no active internet connection (air-gapped audit environments, branch audit computers), download these 3 standalone scripts and save them in the exact same directory alongside index.html:

Library Save As Filename Official URL
PDF-Lib pdf-lib.min.js Download PDF-Lib
PDF.js pdf.min.js Download PDF.js
Tesseract.js tesseract.min.js Download Tesseract.js
Once saved locally, change the script tags in index.html from URLs to: <script src="pdf-lib.min.js"></script>, etc.

⚖️ Privacy Safeguards & Legal Disclaimer

1. Client-Side Privacy Guarantee:
Suresh PDF executes all parsing, extraction, splitting, merging, and cryptographic operations exclusively in the local browser runtime memory. No document data, financial records, client names, or extracted figures are ever uploaded, transmitted, or logged to external cloud servers.

2. Digital Personal Data Protection (DPDP) Act Disclaimer:
While offline client-side document processing eliminates third-party transmission risks, simply utilizing an offline tool does not inherently confer full regulatory compliance under the DPDP Act 2023 or ICAI guidelines. Chartered Accountants and article trainees remain responsible for physical device security, endpoint encryption, and authorized data governance protocols within their firms.

3. No Financial Warranty:
Suresh PDF assists in audit documentation and data restructuring. Extracted figures from OCR or regex parsing must always be cross-checked against original vouchers prior to finalizing tax audit reports or statutory certificates.
